# clinlp — Vietnamese Clinical NLP (Viettel competition)

Extracts medical concepts (symptom / test name / test result / diagnosis / drug) from
free-form Vietnamese clinical text, with character-exact spans, negation/family/history
assertions, and ICD-10/RxNorm candidate codes. See `CLAUDE.md`, `Topic.md`,
`Topic_Analysis.md`, `Sota_research_report.md` for the full problem spec and strategy.

## Status

Early scaffolding. What exists today: the shared contract (`schema.py`), the
position calculator (`position.py`), the validator (`validate.py`), the eval-harness
scorer (`eval/scorer.py`), and the pipeline orchestrator skeleton (`pipeline.py`). NER
rules, entity linking, and data synthesis are being built on top of this (see the
project plan for the phased roadmap and ownership split).

## Setup

Two environments are needed:

1. **Plain Windows/Linux, no GPU required** — for the rule-based baseline, the eval
   harness, and unit tests:
   ```
   pip install -e .
   pip install -r requirements.txt
   ```
2. **Linux (WSL2 or a dedicated cloud GPU box)** — for QLoRA fine-tuning and local LLM
   serving. `bitsandbytes`/`vllm`/flash-attention have weak-to-absent native Windows
   support, so do not attempt to install this on the plain-Windows dev box:
   ```
   pip install -r requirements-llm.txt
   ```

Vietnamese text printed to a Windows console needs UTF-8 output forced:
```
PYTHONIOENCODING=utf-8 python scripts/<script>.py
```

## Running

```
pytest tests/                      # unit tests
python scripts/survey.py           # corpus stats over input/input/*.txt
```

`scripts/run_baseline.py`, `scripts/run_inference.py`, `scripts/make_submission.py`,
and `scripts/build_icd10_index.py` / `scripts/build_rxnorm_index.py` are not yet
implemented — see the project plan's Week-1 gate.

## Reproducing the data

- ICD-10: `data/ICD-10/icd10cm_order_2024.txt` / `icd10cm_codes_2024.txt` are the
  manually downloaded CMS reference files (public domain). `data/ICD-10/icd10_processed.csv`
  (reformatted to dotted codes, bilingual descriptions) is generated by
  `scripts/build_icd10_index.py` — not committed as a large binary artifact.
- RxNorm: not yet downloaded. Planned via the NLM UTS Full Monthly Release and/or the
  RxNorm REST API's bulk `allconcepts` endpoint — see the project plan.
- `data/embeddings/` (retrieval indices) and any model weights are deliberately
  `.gitignore`d — they are rebuilt deterministically by `scripts/build_*_index.py` /
  `ner/train_qlora.py` rather than committed as binaries.

## Competition constraints (do not violate)

- The model used **at inference time** must be self-hosted, ≤9B parameters, no
  external API calls. `ner/llm_extract.py` and `linking/*` must never import
  `requests`/`urllib` — only `dataprep/teacher_client.py` and the one-time
  `scripts/build_*_index.py` scripts are allowed to touch the network.
- External LLM APIs are allowed for offline data preparation only (see `dataprep/`).
